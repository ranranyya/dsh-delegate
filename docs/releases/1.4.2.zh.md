# DSH TaskBridge 1.4.2 更新说明

发布日期：2026 年 11 月 14 日。安装标识：`dsh-taskbridge@1.4.2`。

## 默认通用，不再列举 DSH 兼容版本

本版删除 `engines.dsh`，将宿主提供的 DSH peer 依赖范围改为 `*`。DSH 不再因当前版本号没有出现在插件白名单中，而显示“不兼容”并拒绝加载。截图中的 `DSH 0.2.2-rc.3` 因旧版本范围被拒绝的问题属于本次修复范围。

自定义插件索引同步移除可选的 `engines` 字段，使索引安装和 npm 安装使用一致的默认通用策略。

必要的模型路由、审批、会话等运行时接口检查继续保留；缺失接口时仍报告具体原因。Node.js `>=24` 要求及用于复现测试的固定开发依赖不变。默认通用不是“所有版本均已完成真实任务验收”的声明。

## 其他行为

- 保留 1.4.1 的历史补审、可靠保存、8000 码点审查意见和按需分页读取。
- Codex 集成版本同步更新，并识别已发布的原版 1.4.1 模板；用户自行改过的文件保持原样。
- API、执行模型、思考强度和任务数据使用原有设置。本次不调整权限策略或静默等待流程。

## 更新方式

在 DSH 插件管理中更新，或添加 `dsh-taskbridge@1.4.2`。区域镜像未同步时选择 npm 官方源，也可使用本 Release 的 `.tgz` 与 SHA256 校验文件。订阅自定义索引的用户可刷新发现页。

截图显示的仍是 `dsh-taskbridge@1.4.0`；发布新版本不会改写已安装的旧包，需要实际更新至 1.4.2。无需手动修改 DSH 的版本豁免、正式 profile 或安全设置。
