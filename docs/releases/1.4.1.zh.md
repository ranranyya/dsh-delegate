# DSH TaskBridge 1.4.1 更新说明

发布日期：2026 年 11 月 14 日。安装标识：`dsh-taskbridge@1.4.1`。

让 Claude Code 或 Codex 指挥 DSH 工作，在 DSH 插件中配置 API、执行模型和思考强度。1.4.1 针对 1.4.0 审查报告中的 R1—R5，补齐执行结束后的审查闭环。

## 重启后继续读取和补审

已结束任务保留原 ID。DSH／插件重启后，原指挥端仍可通过结果、等待与审查工具读取已保存记录；完成但尚未审查的任务可直接补审，再次重启仍保留结论。

历史记录是可审查的证据，不会恢复成执行任务，也不会恢复旧权限申请。失败、取消或中断保持真实结局。其他身份与未知 ID 得到一致的拒绝；关闭派工开关后，已有结果读取和审查仍可进行。

历史缺少的输出、差异或关联证据会明确标记。是否足以验收由指挥端判断；插件不会因为历史记录存在便自动通过。

## 保存确认后才显示审查结论

审查结论分为保存中、保存未确认、已保存及确定失败。请求等待超过默认 5 秒，仅表示底层写入尚未确认，不能当作确定失败，也不能提前说审查已记录。

晚到的成功或失败会同步到后续读取和页面。相同审查并发提交共享一次写入，已有结论与冲突请求明确区分；确定失败可重试。任务收尾快照不能覆盖已经保存的审查结论，其他任务的历史写入也不应丢失。

## 8000 字符审查意见完整保存

统一按 **Unicode 码点** 统计，最多 8000，覆盖中文、英文、换行和 emoji。输入仍去除首尾空白并脱敏，合法正文不会再被通用短标签裁到 256 字符；超过限制在写入前拒绝。存储容量不足时明确报告，不能删掉审查正文来宣称保存成功。

以前已被旧版截掉的部分，升级无法自动恢复；需要原对话或报告作为补证。

## 页面和工具各按用途返回内容

- 可见页面在有运行中、待审或保存中记录时每 5 秒刷新；隐藏暂停、恢复立即读取，结论确认后停止。待审不被当作正在执行，也不增加取消入口。刷新失败保留原记录并提示异常。
- 列表只展示最多 200 码点预览，详情可展开和复制全文。剪贴板不可用、同步拒绝或异步失败时准确提示。
- `delegate_wait` 继续简短返回状态，不重复附带长审查正文。
- 旧 `delegate_result({ taskId })` 继续可用。返回大小受限时，备注明确带 `noteOmitted: true` 和 `noteChars`，不会把截短正文冒充全文。
- 需要全文时使用 `delegate_result({ taskId, reviewNoteOffset: 0 })`。默认每页 2000 码点，可用 `reviewNoteLimit` 调整到 1—2000；按 `nextOffset` 续读，到 `complete: true` 结束。分页只读取备注，不重复搬运执行输出和差异。

## Codex 集成与升级

受管理的原版 1.4.0 模板支持 LF／CRLF 精确识别和升级；用户改过的文件保留。新规则强调集中审查、写回确认、按需取全文以及通过 `continueFromTaskId` 续接原任务。

首次安装仍使用插件设置页集成按钮。正式更新后，客户端可能需要重新加载规则和工具目录。历史数据目录、MCP 技术名称和 API／模型选择方式保持兼容。

## 安装与升级

在 DSH 插件管理中更新 `dsh-taskbridge`，或在添加插件时输入 `dsh-taskbridge@1.4.1`。区域镜像未同步时选择 npm 官方源；也可使用本 Release 的 `dsh-taskbridge-1.4.1.tgz` 和 SHA256 校验文件。订阅本项目自定义索引的用户，可在索引部署完成后刷新发现页面获取版本。

升级后按需重新加载 Codex，使客户端重新读取受管理规则和 MCP 工具目录。不要同时启用旧名称的插件副本；既有数据目录和模型设置保持兼容。

## 验证结果与边界

完整自动回归 **1283 项通过**；同步开发仓库后，包内容、历史补审和页面刷新驱动的针对性验证 **48 项通过**。客户端构建及一致性检查、`git diff --check` 通过。

隔离安装包使用实际 stdio MCP 子进程与本机 HTTP 接口，完成原任务 ID 读取、重启后补审、再次重启读回；8000 码点备注经 4 页完整重组。普通等待回复不带备注正文，该次通道验收为 1566 字节。

自动回归覆盖真实历史写盘、超时后成功／失败、同任务并发、其他任务同时保存、收尾重叠、码点边界，以及刷新 hook 与实际 store、剪贴板和临时 Codex 配置迁移。

自动测试使用包内真实模块和临时目录，模型／会话由夹具提供；发布不代替用户正式 Desktop 升级、页面点击验收、真实提供方任务验收或真实客户端长等待验收。

本版没有重新测量账单或整任务 token，不给出新的节省百分比；仅验证长备注不会使普通等待回复按正文长度膨胀。1.4.0 的短样本测量保留其原有适用边界。

本版不包含后续规划的外层静默等待优化、审批后直接恢复等待和减少不必要提权申请。这些问题另行实施与验收。
